# דגם הגוף התלת-ממדי

`body.glb` הוא הדגם שמוצג בפאנל הגוף בדף הטיפול.

## הדגם הנוכחי

**Human Base Meshes Bundle v1.4.1 של Blender Foundation** — הגוף הריאליסטי
הגברי (`GEO-body_male_realistic`), בתנוחת A (ידיים מעט פתוחות, כפות ידיים
לכיוון הירכיים). מקור: `download.blender.org/demo/asset-bundles/human-base-meshes/`.

**רישיון: CC0** (נחלת הכלל) — מותר לכל שימוש, כולל מסחרי, בלי ייחוס. הקובץ
כאן יוצא מהחבילה ב-Blender 5.0 ללא שינוי בצורה: ללא חומרים, ללא טקסטורות,
ללא שלד, רמת Multires 1 (כ-42 אלף קודקודים, 1.5 MB). סקריפט הייצוא: פתיחת
קובץ החבילה, בחירת האובייקט, ייצוא glTF Binary עם `+Y Up`, `Apply Modifiers`,
בלי Draco.

זהו גוף אדם סביר, אבל **לא ייחוס אנטומי מדויק**: שבע נקודות ההדגמה
ב-`features/encounters/body3d/points.ts` הוצבו עליו בעין ומסומנות
`validated: false` עד שמישהו יאמת אותן מול ספר.

## מערכת הצירים שהקוד מצפה לה

| | |
|---|---|
| למעלה | +Y |
| חזית הגוף | +Z |
| שמאל המטופל | +X (מול המצלמה — צד ימין של המסך) |
| ראשית | על הרצפה, בין כפות הרגליים |
| יחידות | מטרים; הגובה מנורמל ל-1.75 m |

הקוד **לא מניח** שהדגם מיוצא כך. הוא מודד את תיבת התחום של הרשת בזמן
טעינה, מכווץ לגובה 1.75 ומזיז את הרגליים לראשית (`body3d/frame.ts`). מה
שכן חייב להיות נכון בקובץ: **הדגם עומד, פונה ל-+Z, ו-+Y למעלה.** הפוך
או שוכב — הקואורדינטות לא יתאימו.

## מגבלות על הקובץ (בגלל מדיניות האבטחה של הדף)

הדף לא מאפשר סקריפטים ומשאבים מחוץ למקור שלו, ולכן:

- **glTF Binary רגיל** (`.glb`) בלבד. **בלי Draco, בלי Meshopt, בלי KTX2** —
  הם מפוענחים דרך worker ו-blob, ואלה חסומים. הדגם פשוט לא יופיע, בלי
  שגיאה ברורה.
- **בלי טקסטורות מוטמעות.** החומר מוחלף ממילא בצבע אחיד מערכת הנושא;
  טקסטורה בקובץ רק תיחסם ותשקול.
- שלד (skinned mesh) בסדר — הדגם מצויר בתנוחת המנוחה שלו; אנימציות
  בקובץ פשוט לא מופעלות.

## החלפה בדגם אחר

1. ב-Blender: הדמות עומדת, פונה ל-−Y של Blender (שהופך ל-+Z בייצוא עם
   **+Y Up** מסומן), `Apply All Transforms`, בלי טקסטורות, ייצוא כ-**glTF
   Binary (.glb)** בלי דחיסה.
2. להחליף את `body.glb` כאן. אין צורך לשנות קוד.
3. לפתוח דף טיפול בפיתוח עם `?pointEditor=1` בכתובת, לבדוק את הנקודות על
   הדגם החדש, ולכוונן ב-`points.ts` (לחיצה על הגוף מעתיקה רשומה מוכנה).
   נקודה שאומתה מול ייחוס — מסמנים `validated: true`.
4. לעדכן את הסעיף "הדגם הנוכחי" כאן, ואת הכיתוב `encounters.body3d.modelCaption`
   בשתי השפות אם צריך.
